# Agent Notes

- This is a **public dotfiles repository**. Assume every file and the full Git history are visible to everyone.
- **Never add secrets** (tokens, passwords, private keys, credentials, or populated `.env` files). Use placeholders, environment variables, and ignored local files instead. Do not print suspected secrets in logs or replies.
- Each top-level directory configures the tool with the same name. Check for a nearer `AGENTS.md` before editing.
- Keep changes minimal and machine-agnostic; preserve existing behavior unless the task requires otherwise.
- Review `git diff` and scan changed files for secrets before finishing.
